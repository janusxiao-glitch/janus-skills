# 可复制提示词模板

将 `{字段}` 替换为用户指定内容；没有特别说明时保留默认值。原图必须作为参考图一并输入。

## 参数

```yaml
head_scale: 1.25             # 最大 1.5
torso_scale: 0.45
arm_scale: 0.35
leg_scale: 0.35
subject_frame_scale: 1.0     # 默认保持人物在画面中的整体占比
face_identity_lock: strict
scene_lock: strict
realism: photographic
extra_user_request: "{用户明确提出的额外要求；无则留空}"
```

## 正向提示词

```text
请以附带的人物照片为唯一视觉参考，对照片中的人物进行“写实大头小身子/Chibi 微缩人物”特效重绘。

只修改人物身体比例，以及在 {subject_frame_scale} 下用户明确要求的整个人物画面占比；原图的背景、场景布局、机位、构图、人物位置、透视、景深、全局光影、天气和色彩氛围全部保持不变。

比例参数：头部相对原图放大 {head_scale} 倍；躯干缩小到约 {torso_scale}；手臂缩小到约 {arm_scale}；腿部缩小到约 {leg_scale}。头部只能轻微放大，绝不超过 1.5 倍。身体缩小必须保持原本的动作方向、关节关系、重心、姿态和与手持道具的接触关系，不得改变动作含义。

严格保持人物本人的脸部身份和细节：脸型、五官位置、眼神、表情、肤色、发型、发丝、年龄特征和可识别特征与原图一致；不要美颜、换脸、重塑五官或卡通化脸部。严格继承原图的服装款式、颜色、材质、褶皱、鞋子、配饰、手持物和其他道具。

最终效果必须是照片级写实的真实微缩人物：皮肤、头发、布料和道具保持真实摄影质感；人物与地面、家具、道具和环境之间有自然的尺度关系、接触阴影、反射和遮挡；光线方向、色温、噪点、镜头质感和景深与原图一致。由于身体缩小而露出的区域，要使用原场景纹理无痕补全，不能出现拼接边缘或重复纹理。

用户额外要求：{extra_user_request}
```

## 禁止项 / Negative prompt

```text
不要卡通、动漫、插画、绘本、漫画、3D 渲染、CGI、玩偶、黏土模型、塑料质感、玩具感、低多边形、夸张美颜、磨皮、换脸、年龄改变、发型改变、五官改变、表情改变、服装改变、颜色改变、道具改变、动作改变、背景替换、场景改变、机位改变、构图改变、天气改变、时间改变、额外人物、额外肢体、断肢、重影、手指错误、身体穿模、漂浮、错误透视、错误接触阴影、硬边抠图、拼接痕迹、重复纹理、透明空洞、文字、水印、边框、过度锐化、过度模糊、失真、非照片级质感。
```

## 输出流程模板

```text
编辑目标：写实大头小身子人物重绘
参考图：附带的人物照片
参数：head_scale={head_scale}; torso_scale={torso_scale}; arm_scale={arm_scale}; leg_scale={leg_scale}; subject_frame_scale={subject_frame_scale}
锁定项：face_identity_lock={face_identity_lock}; scene_lock={scene_lock}; realism={realism}
执行：先按正向提示词进行一次参考图编辑，再按禁止项复核。
验收：确认脸部身份、服装/道具、动作/表情、背景/构图/光影均未被无关改变，且身体比例变化自然、无拼接和重影。
```
