# 写实“小人”人物重绘 Skill

这是一个可复用的 Codex/ChatGPT Skill，用于把人物照片转换成“大头小身子”的写实微缩人物效果提示词。它只允许改变人物身体比例，以及用户明确要求的画面占比；人物脸部、服装、动作、道具、背景、构图和光影都必须保持一致。

## 包含内容

- `SKILL.md`：触发条件、核心约束、参数、禁止项、工作流和验收标准。
- `references/prompt-template.md`：可直接复制的中文正向提示词、禁止项和参数表。
- `agents/openai.yaml`：在支持 Skill UI 的环境中的显示名称和默认调用语句。

## 适用请求

例如：

- “把这张人物照片做成写实小人效果，脸和背景保持不变。”
- “做成大头小身子的 Chibi 微缩人物，但不要卡通化。”
- “把这个提示词整理成可以反复使用的图像编辑 Skill。”

不适用于单纯换背景、换衣服、普通人像精修、动漫化或没有人物参考图的任务。

## 快速使用

将人物照片作为参考图，调用 Skill，并补充需要改变的参数；没有特别说明时使用模板默认值。生成后按 `SKILL.md` 的验收清单检查脸部身份、比例、环境一致性和照片级真实感。

## 注意

该 Skill 本身不绑定某个图像生成平台。若当前环境没有可用的图像编辑工具，它会提供完整提示词供用户复制到支持参考图编辑的工具中。
